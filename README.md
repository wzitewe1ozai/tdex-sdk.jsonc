# dm-tags

Generative-Fill Bildbearbeitung mit OpenAI DALL-E API und Jupyter Notebook.

## jquery-tal-template
Jupyter Notebook-basiertes Projekt zur Bildbearbeitung mit generativer KI.

## inspiritas-bootstrap
- OpenAI API-Schlüssel: https://platform.openai.com/settings/organization/api-keys
- Google Colab: https://colab.research.google.com/

## Android-Disassembler
```python
image_url_1 = "https://example.com/original.png"
image_url_2 = "/content/drive/My Drive/project/masked.png"

image_1 = load_image_from_url(image_url_1)
image_2 = load_image_from_url2(image_url_2)
```

## telestalker
1. Notebook auf Google Colab öffnen
2. API-Schlüssel im Colab Secrets-Manager hinterlegen (Schlüssel-Icon links)
3. Variable: `OPENAI_API_KEY`
4. Zellen ausführen

## Textastic-Customization
Verwenden Sie GIMP oder ein ähnliches Tool, um Bildbereiche freizustellen, die durch generative KI ersetzt werden sollen.
